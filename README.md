Na minha experiência com suporte de TI, uma das minhas tarefas era controlar o inventário de notebooks por número de série: quem estava com qual equipamento, o que estava em manutenção, o que voltou.

No projeto de Banco de Dados da faculdade, transformei essa rotina num sistema web completo. 💻

🔹 Cadastro de funcionários e equipamentos (CRUD completo)
🔹 Controle de empréstimos e devoluções, com o status do equipamento mudando automaticamente
🔹 Painel com o resumo do inventário em tempo real

O que mais aprendi:
✅ Modelar um banco relacional no MySQL, com chaves estrangeiras protegendo o histórico
✅ Proteger a aplicação contra SQL Injection e XSS
✅ Guardar credenciais fora do código e usar um usuário de banco com o mínimo de permissões
✅ Tratar erros para o usuário ver uma mensagem clara, e não uma tela quebrada

Tecnologias: Python, Flask, MySQL, HTML, CSS e JavaScript.

O código está no meu GitHub (link nos comentários). Feedbacks são muito bem-vindos!
